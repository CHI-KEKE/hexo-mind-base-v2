<!-- tab 取餘數-->

我們的人生，其實一直在「取餘數」。  情緒、記憶、學習、努力都不會線性遞增，而是像 `%` 一樣，在週期中反覆歸零、再度啟程。

有時你覺得自己白學了、白走了，那不代表歸零，而是走到了週期的端點。  正如程式中的 `(value % max) + 1`，每一次「重來」，其實都讓下一次更穩、更深、更有方向

時間並非直線，而是一個緩慢旋轉的螺旋。我們以為在重複，其實在上升。我們以為忘記，其實在沉澱

<!-- tab modulo operation-->

modulo operation，代表著一個循環的時間軸

| 場景   | 用法                            | 解釋             |
| ---- | ----------------------------- | -------------- |
| 日誌   | `if (i % 100 == 0)`           | 每 100 筆印一次進度   |
| 遊戲   | `if (frameCount % 60 == 0)`   | 每秒（60 幀）更新一次畫面 |
| 備份   | `if (dayCount % 7 == 0)`      | 每 7 天備份一次資料    |
| 批次任務 | `if (index % batchSize == 0)` | 每批結束時觸發事件      |

<!-- tab spiral learning-->

9 天內學會 3 個日文詞彙，每天會複習一次，每三天會加強記憶深度

我們需要把 `週期 (%) 的節奏`，結合 `遞進的權重`


![4](https://raw.githubusercontent.com/CHI-KEKE/pics/refs/heads/main/Logi/Modulo/5_learning.png)


```csharp
void Main()
{
	var allen = new Learner();
	var knowledge = new List<string>(){"齒磨きした", "宿題やった", "お片付けした"};
	allen.Learn(9,knowledge);
}

public class Learner
{
	
	private Dictionary<string,(int phase, double depth)> memory = new();
	public void Learn(int days, IEnumerable<string> knowledge)
	{
		Console.WriteLine("🌊 記憶的潮汐開始流動...\n");
		for(int i = 1; i <= days; i++)
		{
			foreach(var word in knowledge)
			{
				if(memory.ContainsKey(word) == false)
				{
					memory[word] = (0,0);
				}
				
				//// 記憶深度在達到一個週期才會提高,時間的週期性、節奏
				var (phase,depth) = memory[word];
				var newPhase = phase % 3 + 1;
				if(newPhase == 1)
				{
                    //// 記憶的逐漸累積
					depth += 0.5;
				}
				
				memory[word] = (newPhase,depth);
				Console.WriteLine($"  🧩 {word,-6}：階段 {phase+1}、記憶強度 {depth:F1}");
			}

			Console.WriteLine($"🌙 第 {i} 天結束，知識在腦中慢慢沈澱...\n");
			Thread.Sleep(300);
		}
		
		Console.WriteLine("✨ 潮水退去，但痕跡留在心裡。");
	}
}
```

<!-- tab SQL - 有界的計數器（Bounded Counter）-->


為了讓計數器永遠不超過一個上限，並循環歸零再起, 當 UpdateTimes 遞增到 255 之後，再加 1 會回到 1，而不是 256

TINYINT 最大值 (0~255)
```sql
UPDATE Table SET UpdateTimes = (UpdateTimes % 255) + 1
```


| 舊的 UpdateTimes | `% 255` 結果 | 新的 UpdateTimes = `%255 + 1` |
| :------------: | :--------: | :-------------------------: |
|        1       |      1     |              2              |
|        2       |      2     |              3              |
|       254      |     254    |             255             |
|       255      |      0     |         1 ✅ ← 循環回來！         |

這樣可以保持數值在 1～255 的範圍內循環遞增, 也就是說，它在實現一種bounded counter（有界計數器）

<!-- tab 批次的節奏 — 分段處理的智慧-->

將資料拆批處理
```csharp
void Main()
{
    // 模擬處理大量資料，每次處理固定數量
    var dataList = Enumerable.Range(1, 100).ToList();
    ProcessDataWithCounter(dataList);
}

public void ProcessDataWithCounter(List<int> dataList)
{
    int processedCount = 0;
    int batchSize = 10;
    int index = 0;
    
    while (index < dataList.Count)
    {
        // 處理當前項目
        var currentItem = dataList[index];
        Console.WriteLine($"處理項目: {currentItem}");
        
        processedCount++;
        index++;
        
        // 每處理 10 個項目就暫停一下
        if (processedCount % batchSize == 0)
        {
            Console.WriteLine($"已處理 {processedCount} 個項目，暫停 100ms...");
            Thread.Sleep(100);
        }
    }
    
    Console.WriteLine($"總共處理了 {processedCount} 個項目");
}
```
