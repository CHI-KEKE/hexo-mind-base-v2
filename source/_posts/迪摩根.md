<!-- tab 本質-->


迪摩根定理在做的事是，把「整坨條件的否定」拆成「每個條件各自反過來」，並且把 AND / OR 對調，本質意義是**當你否定一個「整體判斷」時，其實是在找出讓這個整體失敗的所有可能原因**



![2](https://raw.githubusercontent.com/CHI-KEKE/pics/refs/heads/main/Probability/de-morgan/3_essence.png)



常見形式是

```bash
!(A && B) === !A || !B ## 不是「A 和 B 都成立」等於「A 不成立」或「B 不成立」


!(A || B) === !A && !B ## 不是「A 或 B 其中一個成立」等於「A 不成立」而且「B 不成立」
```


![2](https://raw.githubusercontent.com/CHI-KEKE/pics/refs/heads/main/Probability/de-morgan/2_trick.png)



要證明「他同時有登入且有權限」失敗，只要發現他沒登入，或沒權限，任一個成立就夠

<!-- tab 進入後台的條件-->


![2](https://raw.githubusercontent.com/CHI-KEKE/pics/refs/heads/main/Probability/de-morgan/4_authority.png)



假設進入後台的條件是：必須登入，而且必須是管理員

程式可能寫成
```csharp
const canEnterAdmin = isLogin && isAdmin;
```
這個條件成立的要求很嚴格登入 ✅ + 是管理員 ✅ = 可以進入

那什麼情況不能進入？
```csharp
const cannotEnterAdmin = !(isLogin && isAdmin);
```

用迪摩那一根定理拆開
```csharp
const cannotEnterAdmin = !isLogin || !isAdmin;
```

意思是沒登入，或不是管理員，就不能進入

這裡的本質很重要

「允許進入」需要所有條件都滿足
「拒絕進入」只需要其中一個必要條件壞掉




<!-- endtab -->


<!-- tab 年齡-->


例如條件是：

```BASH
age >= 18 && age <= 65
```

意思是年齡在 18 到 65 歲之間

那「不在這個範圍內」是：

```BASH
age < 18 || age > 65
```

也就是小於 18，或大於 65。這背後就是迪摩根定理：

```BASH
!(age >= 18 && age <= 65)

```

等於

```bash
age < 18 || age > 65
```

它的本質是幫你把「範圍內」精準翻成「範圍外」。這在表單驗證、資格判斷、資料篩選裡非常常見
